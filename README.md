# FlowBuild website

Static website for FlowBuild. No build process or dependencies.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Current scope

This package is for local review only. Repository creation, hosting, DNS changes, and production publishing are intentionally out of scope.

The SVG logo is an approximate Core Flow placeholder. Replace it with the final approved asset before launch. PickOne is marked as in development.
